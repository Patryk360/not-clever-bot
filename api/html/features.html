Możliwości i Dokumentacja

Dowiedz się, jak komunikować się z naszym botem za pomocą prostych zapytań HTTP GET.

🧠

Auto-Nauka

Bot uczy się w locie. Jeśli czegoś nie wie, dopyta Cię o odpowiedź i zapisze ją w bazie danych.

🧮

Obliczenia

Wysyłaj działania matematyczne (np. 5+5), a bot zwróci gotowy wynik dzięki bibliotece Math.js.

🌐

Wiedza Świata

Gdy brakuje wiedzy lokalnej, bot automatycznie przeszuka polską Wikipedię w poszukiwaniu definicji.

Jak wysyłać zapytania?

Nasz bot przyjmuje zapytania za pomocą parametru sentence w adresie URL.

💬 Zwykła rozmowa
/api/response?sentence=Cześć co tam?&key=TEST Bot sprawdzi bazę wiedzy i odpowie naturalnie.
🧮 Matematyka
/api/response?sentence=Ile to 10*5?&key=TEST Zwróci wynik: 50 (pamiętaj o kodowaniu znaku + jako %2B).
🌐 Szukanie informacji
/api/response?sentence=Polska&key=TEST Bot pobierze wstęp z Wikipedii na temat podanego hasła.
✍️ Uczenie bota
/api/response?sentence=Moja odpowiedź&key=TEST Wyślij odpowiedź zaraz po tym, jak bot zapyta "Co powinienem odpowiedzieć?".
